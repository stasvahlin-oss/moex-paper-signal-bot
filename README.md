# MOEX Paper Signal Bot

Отдельный Telegram-бот для **бумажных** 5-минутных сигналов по ликвидным акциям Московской биржи.

## Возможности

- свечи MOEX ISS с интервалом 5 минут;
- EMA9/EMA21, RSI, VWAP, объём и пробой локального максимума;
- простой новостной фильтр по RSS-заголовкам;
- виртуальные BUY-сигналы со сроком 5 минут;
- цель, стоп, модельный PnL и журнал в SQLite;
- уведомления в Telegram;
- `/report`, `/export`, `/final_report`, `/scan`;
- автоматическая остановка после 500 закрытых бумажных сделок не включена: сканирование можно оставить для накопления статистики, а `/final_report` проверяет порог.

## Важные ограничения

Бот не подключается к брокеру и не размещает, не изменяет и не отменяет заявки. Все сделки гипотетические. 5-минутный сигнал не может быть 100% гарантированным. MOEX ISS и RSS могут быть задержаны или временно недоступны; это фиксируется в логах.

## Переменные Render

```text
TELEGRAM_BOT_TOKEN=токен отдельного бота
ADMIN_CHAT_ID=ваш числовой Telegram chat id
```

Токен не публикуйте в GitHub и не отправляйте в чат. `ADMIN_CHAT_ID` ограничивает уведомления и команды одним пользователем.

## Первый запуск

1. Создайте отдельного бота через `@BotFather`.
2. Создайте GitHub-репозиторий и загрузите `bot.py`, `requirements.txt`, `render.yaml`, `README.md`, `.gitignore`.
3. На Render создайте **Web Service** из репозитория.
4. Добавьте `TELEGRAM_BOT_TOKEN` и `ADMIN_CHAT_ID` в Environment Variables.
5. После деплоя отправьте боту `/start`, затем `/scan`.
6. Статистику смотрите через `/report`, полный CSV скачивайте через `/export`.

## Данные

По умолчанию сканируются `SBER,GAZP,LKOH,YNDX,ROSN,TATN,MOEX,GMKN,NVTK,VTBR`. Список можно изменить переменной `MOEX_TICKERS`.

SQLite-файл на бесплатном Render может потеряться при пересоздании сервиса. Для надёжного накопления 500 сделок нужно подключить постоянное хранилище или регулярно скачивать `/export`.
